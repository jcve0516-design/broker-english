# 词汇学习 · Vocab Trainer

面向**证券行业 IT 产品经理**的场景化职业英语训练 App。纯浏览器、无后端、无需联网，双击即用；数据存在本地浏览器（localStorage）。

> 使用者背景：金融行业 IT 产品经理，负责证券交易清算系统产品管理。
> 学习目标：听说读写全面提升 —— 看懂各国交易所交易/清算文件、与美国同事开英语会议、日常英语沟通。

---

## 快速开始

- **直接用单文件**：双击 `vocab-trainer.html`，浏览器打开即可（已内置两个示例词库 + 深色模式，可离线使用，方便分享）。
- **开发/分文件版**：打开 `index.html`（需要和 `styles.css` / `app.js` / `samples.js` 在同一目录）。
- **首次使用**：概览页或"导入"页点一下"内置示例词库"即可一键载入，立即开始练习。

推荐浏览器：Chrome / Edge（发音、以及后续的语音识别支持最好）。

## 安装到 iPhone（做成主屏 App）

本 App 已做成 **PWA**（渐进式网页应用），可添加到 iPhone 主屏、全屏运行、离线使用，**无需 Xcode、无需 App Store、无需开发者账号**。

### 方式一：托管到 HTTPS（推荐，可离线）
1. 把整个 `english-app/` 目录传到任意静态托管（GitHub Pages / Netlify / Vercel 均免费）。
2. iPhone 用 **Safari** 打开该 https 网址。
3. 点底部「分享」→「添加到主屏幕」→ 完成。
4. 首次联网打开后，Service Worker 会缓存全部资源，之后**断网也能用**。

> 需要 HTTPS 或 localhost，Service Worker（离线）才会生效——这是 Safari 的安全限制。

### 方式二：Mac 局域网自测（快速试用）
1. 在 `english-app/` 目录运行：`python3 -m http.server 8000`
2. 查 Mac 的局域网 IP（系统设置 → 网络），iPhone 与 Mac 同一 Wi-Fi。
3. iPhone Safari 打开 `http://<Mac的IP>:8000` → 分享 → 添加到主屏幕。
   （注意：纯 http 局域网下离线缓存可能不生效，先联网用；要离线请用方式一。）

### 方式三：真正的原生 .ipa（可选，需 Xcode）
用 [Capacitor](https://capacitorjs.com/) 把网页封装成原生壳，再用 Xcode 安装到自己手机：
```bash
cd english-app
npm init -y && npm i @capacitor/core @capacitor/cli @capacitor/ios
npx cap init "词汇学习" com.yourname.vocab --web-dir .
npx cap add ios
npx cap copy
npx cap open ios      # 打开 Xcode
```
在 Xcode 里：选中 target → Signing & Capabilities → 选你的 Apple ID（个人免费账号签名可用 **7 天**，付费开发者账号 **1 年**）→ 连接 iPhone → 点运行安装。
> 此步骤需在你本机手动完成（签名 / 连接设备 / 点击运行无法由脚本代替）。

单文件版 `vocab-trainer.html` 也可直接存到 iPhone「文件」App 用 Safari 打开，但那是网页标签、非主屏独立 App。

## 当前已实现功能

- **导入**：Markdown 表格 / CSV / TSV / 纯文本，自动识别列、跳过目录等非词表；按分类+词条去重。
- **五种练习**：卡片翻背、选择题（中英互测）、拼写、听写（听发音写内容）、口语跟读（朗读并按词自动打分）。单词/例句两种模式。
- **文档阅读**：粘贴真实英文文档，自动高亮词库术语（悬停释义、点击朗读），可切换挖空模式做填空回忆；内置 7 篇交易所/清算/托管风格阅读语料可下拉一键载入。
- **写作练习**：中→英造句（对照参考答案自评）+ 邮件/会议写作模板库（占位符高亮、一键复制）。
- **四维能力看板**：概览页按听说读写分别统计练习量与正确率，提示最该补的一项。
- **发音**：Web Speech API 朗读，可选发音（voice）与语速；无语音环境自动隐藏。
- **间隔重复**：SM-2 简化算法，按记忆程度安排下次复习。
- **进度体系**：连续天数、每日目标、最近 14 天复习量柱状图。
- **学习增强**：多分类同时学、难词优先。
- **数据管理**：JSON 备份/恢复（含词条、每词进度、连续天数、复习量、四维看板与设置）、难词导出（Markdown / Anki CSV）。
- **内置示例**（6 套）：券商 IT 高频术语表（116 词）、券商 IT 英语词汇表（2017 词）、交易/清算/资产（业务与系统，126 词）、全球交易所与清算机构（专名缩写，70 词）、会议沟通与邮件写作句式（70 句）、全球交易清算规则专有术语（64 词），一键载入。
- **体验**：深色模式（跟随系统、可切换、防闪烁）、键盘快捷键、响应式布局。

## 能力盘点（技能 × 场景 差距分析）

目标本质是**四项技能 × 三个真实场景**。现状偏"读/记"，听说与文档级阅读较弱：

| 技能 | 真实场景 | 现状覆盖 | 缺口 |
|------|---------|---------|------|
| 读 | 交易所公告、清算/交收文件、FIX/ITCH 规范 | 术语卡片、例句、**文档阅读（术语高亮+挖空）** | 缺整篇长文的结构化理解、生词自动收集 |
| 听 | 与美国同事开会、电话会 | TTS 朗读 + **听写（单词/例句）** | 仍缺连读/口音适应、真实会议语料 |
| 说 | 会议发言、澄清、跟进 | **口语跟读 + 发音自评（按词打分）** | 缺连贯对话/角色扮演、云端级评分 |
| 写 | 邮件、需求文档、评论 | **中→英造句 + 邮件/会议模板库** | 缺自由写作的智能批改（需外部模型） |

结论：下一步补齐**听、说、写**三项短板 + **文档级阅读**，而非继续堆通用背词功能。

## 路线图

状态标记：`[ ]` 待做　`[~]` 进行中　`[x]` 已完成

### 阶段 A — 听 & 写基础（纯浏览器，成本低，优先）
- [x] **A1 听写模式（Dictation）**：只播英文发音 → 用户打出来。练"听"+"拼写"。含播放/重播/慢速、可选中文提示、答案宽松比对（忽略大小写与标点），并接入间隔重复。
- [~] **A2 句子/例句模式**：听写已支持"例句"模式（播放例句/整句会议表达并听写）。跟读部分留待阶段 B。

### 阶段 B — 说（依赖浏览器语音识别）
- [x] **B1 口语跟读 + 发音自评**：显示句子 → 范读 → 点麦克风朗读 → `SpeechRecognition` 转写并与原文按词（LCS）比对打分（0-100），标出"待加强"的词，接入间隔重复。支持单词/例句两种模式。
  - 约束：依赖 Chrome/Edge 的 Web Speech API 且需麦克风权限；Safari/Firefox 不支持时会自动隐藏"口语"入口。

### 阶段 C — 读（文档级，最贴合日常）
- [x] **C1 文档阅读 + 术语高亮**：粘贴英文段落，按词库做贪心最长匹配（支持 order book、clearing house 等 1–5 词短语），高亮命中术语，悬停看中文、点击朗读。含"载入示例段落"。
- [x] **C2 挖空练习（Cloze）**：一键切换"挖空模式"，把命中的术语变成空格，点击显示答案并朗读，把"看文件"变成填空回忆练习。

### 阶段 D — 写 & 复盘
- [x] **D1 写作练习**：①中→英造句（用"整句"类词条做中译英，写完对照参考答案 + 朗读，自评接入间隔重复）；②邮件/会议写作模板库（请求/跟进/确认/上报/约会/纪要 + 会议开场/澄清/表态/推进/收尾，占位符高亮，一键复制）。
- [x] **D2 听说读写四维看板**：概览页新增四维能力面板，按技能（听←听写、说←口语、读←卡片/选择、写←拼写/造句）分别统计练习量与正确率，用柱条对比、并高亮"练得最少"的一项给出建议。

## 开发者说明

### 重新生成内置示例
编辑 `gen_samples.mjs` 顶部的 `SOURCES` 列表（可增删源 md 词表），然后：

```bash
node english-app/gen_samples.mjs
```

会依据与 App 一致的解析逻辑重新生成 `samples.js`。

### 重新构建单文件
```bash
node english-app/build.mjs
```

把 `styles.css` / `samples.js` / `app.js` 内联进 `index.html`，输出 `vocab-trainer.html`。
（构建脚本用函数式替换规避 `$` 特殊模式问题，并校验无外链残留。）

### 典型改动流程
1. 改 `app.js` / `styles.css` / `index.html`；
2. 如改了词表源：`node gen_samples.mjs`；
3. 出分发版：`node build.mjs`。

## 已知约束

- **数据仅存本地浏览器**：清除站点数据会丢失进度；重要数据请用"导出备份"。单文件版换设备也不共享进度，用 JSON 备份迁移。
- **JSON 备份含词条、每词进度、连续天数、复习量、四维看板与设置**。恢复时勾选"覆盖"完整还原（适合换设备）；默认"合并"只新增词条、不改动现有统计（避免每日复习量被重复累加）。
- **语音能力依赖浏览器**：发音质量随系统/浏览器不同；语音识别（阶段 B）主要在 Chrome/Edge 可用。
- **无 AI 反馈（当前）**：写作/口语的智能评分需接入外部模型，离线版暂以模板/规则实现。
